# berlin-analytics-hub #
## An AI-assisted coding project ##

For this project, I set out to create a website that showcases a range of metrics and analytics about Berlin, organized by topic—such as finance, healthcare, neuroscience, life sciences, and more.

The site is a dashboard-style public platform hosted on GitHub Pages, featuring visualizations of key economic sectors in Berlin, with special attention to niche areas I’m particularly interested in, including neuroscience and neurotechnology.

The project is originally set up using Perplexity Labs:
[P search](https://www.perplexity.ai/search/i-want-to-setup-a-site-that-sh-6_WkZdusQnaYBW3j._IcfA?0=d)

The web scraper file is called berlin-scraper.py in the scripts folder
